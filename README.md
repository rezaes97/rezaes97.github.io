## Deployment

This repository is configured for GitHub Pages. To publish from the repository:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/(root)` folder, then save.
4. GitHub Pages serves the homepage from `index.html`.

The site is a self-contained static HTML page and does not require a build step or external JavaScript dependencies.
